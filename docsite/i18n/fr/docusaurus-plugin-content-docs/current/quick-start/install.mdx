# Installer Anda

Anda Bot peut être installé depuis une version publiée (release) ou exécuté directement depuis le code source du dépôt. Les versions publiées sont optimales pour un usage quotidien ; les builds à partir des sources sont recommandés pour contribuer, déboguer ou expérimenter de nouvelles fonctionnalités.

## Installer la dernière version

### Anda Desktop

La plupart des utilisateurs devraient commencer par Anda Desktop : la fenêtre de discussion, l'espace de travail et l'icône de la barre système. Téléchargez-le depuis la [dernière version](https://github.com/ldclabs/anda-bot/releases/latest) :

- macOS Apple Silicon : `Anda-mac-arm64.dmg`
- Windows x64 : `Anda-win-x64.exe`
- Homebrew : `brew install --cask ldclabs/tap/anda-desktop` (installe aussi la formule `anda`)

Les nouvelles versions macOS en ligne de commande et de bureau sont réservées à Apple Silicon. Sur Mac Intel, compilez depuis les sources.

Anda Desktop conserve une installation `anda` existante, ou installe son `anda` intégré et les compétences sélectionnées là où les scripts d'installation les placent (`~/.local/bin` sur macOS, `%LOCALAPPDATA%\Programs\AndaBot` sur Windows). Le bureau, le terminal et l'extension Chrome partagent alors un seul runtime et un seul démon. Le guide de connexion du modèle propose une option de démarrage à l’ouverture de session. L'icône d'Anda Desktop remplace le lanceur retiré de la barre de menus d'Anda Bot, que le bureau supprime.

Si aucun modèle n’est configuré, **Connecter un modèle** s’ouvre automatiquement. Connectez-vous avec ChatGPT et confirmez un modèle, ou choisissez un modèle prédéfini du fichier `config.yaml` intégré et saisissez sa clé API. Le guide attend le chargement du modèle. **Configurer plus tard** conserve le brouillon et un rappel ; rouvrez le guide depuis **Paramètres → Général → Connecter un modèle**. Les configurations existantes sont réutilisées.

### Ligne de commande uniquement

Avec Homebrew :

```bash
brew install ldclabs/tap/anda
```

macOS et Linux avec le script d'installation :

```bash
curl -fsSL https://raw.githubusercontent.com/ldclabs/anda-bot/main/scripts/install.sh | sh
```

Si vous avez aussi une installation Homebrew, ouvrez un nouveau terminal et vérifiez que `command -v anda` pointe vers `~/.local/bin/anda` ou votre `ANDA_INSTALL_DIR` ; sinon, un ancien binaire Homebrew peut masquer le binaire mis à jour par le script.

Windows avec PowerShell :

```powershell
irm https://raw.githubusercontent.com/ldclabs/anda-bot/main/scripts/install.ps1 | iex
```

Les scripts d'installation installent `anda` et les compétences sélectionnées, l'ajoutent au `PATH`, enregistrent le démarrage du démon à la connexion avec `anda autostart install` et le redémarrent ; les relancer supprime aussi le lanceur retiré. Sous Windows, l'entrée de connexion exécute `anda start` et affiche brièvement une console. Pour PowerShell, ajoutez `-NoAutostart` ou `-NoStart` pour refuser ; pour l'installateur shell, définissez `ANDA_NO_AUTOSTART=1` ou `ANDA_NO_START=1`.

Après l'installation, ouvrez un nouveau terminal et lancez :

```bash
anda
```

## Préparer une clé API de modèle

Vous devez disposer d'au moins une clé API de fournisseur de modèle. Les utilisateurs d'Anda Desktop peuvent la saisir dans **Paramètres → Configuration de l'agent**. Les utilisateurs de l'interface en ligne de commande (CLI) peuvent commencer par définir une variable d'environnement :

```bash
DEEPSEEK_API_KEY=VOTRE_CLE_API anda
```

Sous Windows PowerShell :

```powershell
$env:DEEPSEEK_API_KEY="VOTRE_CLE_API"; anda
```

Vous pouvez également enregistrer la clé dans `~/.anda/config.yaml` pour une réutilisation ultérieure. La clé `api_key` définie dans le fichier `config.yaml` est prioritaire sur les variables d'environnement.

## Premier lancement

Lors de la première exécution, Anda crée le répertoire de runtime local et le fichier `~/.anda/config.yaml`. Si la configuration est incomplète, l'interface utilisateur de la terminal répertorie les champs manquants.

1. Ouvrez `~/.anda/config.yaml`.
2. Renseignez la famille (`family`), le modèle (`model`), l'adresse de base de l'API (`api_base`) et soit la clé API (`api_key`), soit une variable d'environnement pour le fournisseur de modèle.
3. Enregistrez le fichier.
4. Actualisez les modèles depuis Anda Desktop ou le panneau latéral du navigateur, ou exécutez `anda models reload`.

Configuration minimale de modèle :

```yaml
model:
  active: "deepseek-v4-pro"
  providers:
    - family: anthropic
      model: "deepseek-v4-pro"
      api_base: "https://api.deepseek.com/anthropic"
      api_key: "VOTRE_CLE_API" # Peut être laissé vide lorsque DEEPSEEK_API_KEY est défini
      labels: ["pro", "brain"]
      disabled: false
```

Le label `brain` permet au cerveau de mémoire de privilégier ce fournisseur. Si aucun fournisseur ne possède ce label, les tâches de mémoire utiliseront le modèle actif.

## Exécuter depuis le code source

Pour exécuter le projet directement à partir du dépôt :

```bash
git clone https://github.com/ldclabs/anda-bot.git
cd anda-bot
cargo run -p anda_bot --
```

Utilisez un répertoire utilisateur (`home`) distinct pour isoler les identités, les projets ou les données de test :

```bash
anda --home /chemin/vers/.anda
```

Commande équivalente à partir des sources :

```bash
cargo run -p anda_bot -- --home /chemin/vers/.anda
```

## Mettre à jour

S'il a été installé via le script d'installation, mettez à jour Anda avec :

```bash
anda update
```

Les installations Homebrew se mettent à jour avec `brew upgrade anda`. **Vérifier les mises à jour**, dans l'icône de la barre système d'Anda Desktop ou dans les Paramètres, vérifie à la fois `anda` et l'application de bureau. L'installation du runtime attend la fin des tâches actives ; la vérification du bureau se poursuit, que cette mise à jour soit installée, reportée ou en échec. Les versions signées du bureau se mettent à jour sans arrêter le service ; les builds non signés nécessitent d'installer manuellement le nouveau paquet de bureau.

Gérez le démon d'arrière-plan à l'aide de :

```bash
anda status
anda start
anda stop
anda restart
anda autostart status
```
