# تثبيت Anda

يمكن تثبيت Anda Bot من إصدار رسمي (release) أو تشغيله مباشرة من مصدر المستودع. تعد الإصدارات الرسمية هي الأفضل للاستخدام اليومي؛ بينما تعد عمليات البناء من المصدر هي الأفضل للمساهمة والتصحيح وتجربة الميزات الجديدة.

## تثبيت الإصدار الأخير

### Anda Desktop

يُنصح معظم المستخدمين بالبدء بـ Anda Desktop: نافذة الدردشة ومساحة العمل ورمز شريط النظام. نزّله من [أحدث إصدار](https://github.com/ldclabs/anda-bot/releases/latest):

- macOS Apple Silicon: `Anda-mac-arm64.dmg`
- Windows x64: `Anda-win-x64.exe`
- Homebrew: `brew install --cask ldclabs/tap/anda-desktop` (يثبّت أيضًا صيغة `anda`)

إصدارات macOS الجديدة لسطر الأوامر والتطبيق تدعم Apple Silicon فقط. يمكن لمستخدمي Mac بمعالج Intel البناء من المصدر.

يحتفظ Anda Desktop بتثبيت `anda` الموجود، أو يثبّت `anda` المضمّن والمهارات المختارة في المكان الذي تستخدمه سكربتات التثبيت (`~/.local/bin` على macOS و`%LOCALAPPDATA%\Programs\AndaBot` على Windows). وبذلك يشترك التطبيق والطرفية وإضافة Chrome في runtime واحد وdaemon واحد. يتيح دليل ربط النموذج تشغيل Anda عند تسجيل الدخول. يحل رمز Anda Desktop في شريط النظام محل مشغّل شريط القوائم القديم Anda Bot، ويزيله التطبيق.

إذا لم يُضبط نموذج، يفتح **ربط نموذج** تلقائيًا. سجّل الدخول باستخدام ChatGPT وأكّد النموذج، أو اختر نموذجًا جاهزًا من ملف `config.yaml` المضمّن وأدخل مفتاح API. ينتظر الدليل تحميل النموذج. يحتفظ **الإعداد لاحقًا** بالمسودة وتذكير الربط؛ أعد فتحه من **الإعدادات ← عام ← ربط نموذج**. تُستخدم الإعدادات الحالية كما هي.

### سطر الأوامر فقط

باستخدام Homebrew:

```bash
brew install ldclabs/tap/anda
```

على macOS وLinux باستخدام سكربت التثبيت:

```bash
curl -fsSL https://raw.githubusercontent.com/ldclabs/anda-bot/main/scripts/install.sh | sh
```

إذا كان لديك أيضًا تثبيت عبر Homebrew، فافتح طرفية جديدة وتأكد من أن `command -v anda` يشير إلى `~/.local/bin/anda` أو إلى `ANDA_INSTALL_DIR`؛ وإلا فقد يحجب ملف Homebrew الأقدم الملف المحدَّث من السكربت.

على Windows باستخدام PowerShell:

```powershell
irm https://raw.githubusercontent.com/ldclabs/anda-bot/main/scripts/install.ps1 | iex
```

تثبّت سكربتات التثبيت `anda` والمهارات المختارة، وتضيفه إلى `PATH`، وتسجّل تشغيل daemon عند تسجيل الدخول عبر `anda autostart install` ثم تعيد تشغيله؛ كما تزيل إعادة تشغيلها المشغّل القديم. على Windows، يشغّل إدخال تسجيل الدخول `anda start` وتظهر نافذة طرفية لفترة وجيزة. بالنسبة إلى PowerShell، أضف `-NoAutostart` أو `-NoStart` لإلغاء ذلك؛ وبالنسبة لمثبت shell، اضبط `ANDA_NO_AUTOSTART=1` أو `ANDA_NO_START=1`.

بعد التثبيت، افتح طرفية جديدة وقم بتشغيل:

```bash
anda
```

## إعداد مفتاح API للنموذج

تحتاج إلى مفتاح API واحد على الأقل لمزود النموذج. يمكن لمستخدمي Anda Desktop إدخاله من **الإعدادات ← إعداد الوكيل**. بينما يمكن لمستخدمي واجهة سطر الأوامر (CLI) البدء بمتغير بيئة:

```bash
DEEPSEEK_API_KEY=YOUR_API_KEY anda
```

في Windows PowerShell:

```powershell
$env:DEEPSEEK_API_KEY="YOUR_API_KEY"; anda
```

يمكنك أيضاً كتابة المفتاح في `~/.anda/config.yaml` لإعادة استخدامه. المفتاح `api_key` في `config.yaml` له الأولوية على متغيرات البيئة.

## التشغيل الأول

عند التشغيل الأول، يقوم Anda بإنشاء دليل تشغيل محلي وملف `~/.anda/config.yaml`. إذا كان التكوين غير مكتمل، تسرد واجهة مستخدم الطرفية الحقول المفقودة.

1. افتح ملف `~/.anda/config.yaml`.
2. املأ حقول مزود النموذج: العائلة (`family`)، والنموذج (`model`)، ورابط قاعدة API (`api_base`)، وإما مفتاح API (`api_key`) أو متغير البيئة.
3. احفظ الملف.
4. قم بتحديث النماذج من Anda Desktop أو اللوحة الجانبية للمتصفح، أو قم بتشغيل `anda models reload`.

تكوين النموذج الأدنى:

```yaml
model:
  active: "deepseek-v4-pro"
  providers:
    - family: anthropic
      model: "deepseek-v4-pro"
      api_base: "https://api.deepseek.com/anthropic"
      api_key: "YOUR_API_KEY" # يمكن تركه فارغاً عند تعيين DEEPSEEK_API_KEY
      labels: ["pro", "brain"]
      disabled: false
```

تجعل تسمية `brain` دماغ الذاكرة يفضل هذا المزود. إذا لم يكن لدى أي مزود هذه التسمية، فستستخدم مهام الذاكرة النموذج النشط (active).

## التشغيل من المصدر

للشغيل مباشرة من المستودع:

```bash
git clone https://github.com/ldclabs/anda-bot.git
cd anda-bot
cargo run -p anda_bot --
```

استخدم دليلاً رئيسياً (home) منفصلاً لعزل الهويات أو المشاريع أو بيانات الاختبار:

```bash
anda --home /path/to/.anda
```

أمر المصدر المعادل:

```bash
cargo run -p anda_bot -- --home /path/to/.anda
```

## التحديث

إذا تم تثبيت التطبيق باستخدام سكريبت التثبيت، فقم بالتحديث باستخدام:

```bash
anda update
```

قم بإدارة daemon الخلفية باستخدام:

```bash
anda status
anda start
anda stop
anda restart
anda autostart status
```
