# Instalar Anda

Anda Bot se puede instalar desde una versión publicada (release) o ejecutar directamente desde el código fuente del repositorio. Las versiones publicadas son ideales para el uso diario; las compilaciones desde el código fuente son recomendables para contribuciones, depuración y experimentación con nuevas funciones.

## Instalar la última versión

### Anda Desktop

La mayoría de los usuarios debería empezar con Anda Desktop: la ventana de chat, el espacio de trabajo y la bandeja del sistema. Descárguelo desde la [última versión](https://github.com/ldclabs/anda-bot/releases/latest):

- macOS Apple Silicon: `Anda-mac-arm64.dmg`
- Windows x64: `Anda-win-x64.exe`
- Homebrew: `brew install --cask ldclabs/tap/anda-desktop` (también instala la fórmula `anda`)

Las nuevas versiones de línea de comandos y de escritorio para macOS solo admiten Apple Silicon. En Mac con Intel puede compilar desde el código fuente.

Anda Desktop conserva una instalación existente de `anda` o instala el `anda` incluido y las habilidades seleccionadas donde lo hacen los scripts de instalación (`~/.local/bin` en macOS, `%LOCALAPPDATA%\Programs\AndaBot` en Windows). Así, el escritorio, la terminal y la extensión de Chrome comparten un mismo runtime y un mismo daemon. La primera ejecución pregunta si Anda debe iniciarse al iniciar sesión. La bandeja de Anda Desktop sustituye al lanzador retirado de la barra de menús de Anda Bot, que el escritorio elimina.

### Solo línea de comandos

Con Homebrew:

```bash
brew install ldclabs/tap/anda
```

macOS y Linux con el script de instalación:

```bash
curl -fsSL https://raw.githubusercontent.com/ldclabs/anda-bot/main/scripts/install.sh | sh
```

Si también tiene una instalación de Homebrew, abra una nueva terminal y compruebe que `command -v anda` apunta a `~/.local/bin/anda` o a su `ANDA_INSTALL_DIR`; de lo contrario, un binario antiguo de Homebrew puede ocultar el binario actualizado del script.

Windows con PowerShell:

```powershell
irm https://raw.githubusercontent.com/ldclabs/anda-bot/main/scripts/install.ps1 | iex
```

Los scripts de instalación instalan `anda` y las habilidades seleccionadas, lo añaden al `PATH`, registran el inicio del daemon al iniciar sesión con `anda autostart install` y lo reinician; al volver a ejecutarlos también eliminan el lanzador retirado. En Windows, la entrada de inicio ejecuta `anda start` y muestra brevemente una ventana de consola. Para PowerShell, añada `-NoAutostart` o `-NoStart` para omitir este comportamiento; para el instalador de shell, defina `ANDA_NO_AUTOSTART=1` o `ANDA_NO_START=1`.

Después de la instalación, abra una nueva terminal y ejecute:

```bash
anda
```

## Preparar una clave API del modelo

Necesita al menos una clave API de proveedor de modelos. Los usuarios de Anda Desktop pueden introducirla en **Ajustes → Configuración del agente**. Los usuarios de la interfaz de línea de comandos (CLI) pueden comenzar configurando una variable de entorno:

```bash
DEEPSEEK_API_KEY=TU_CLAVE_API anda
```

En Windows PowerShell:

```powershell
$env:DEEPSEEK_API_KEY="TU_CLAVE_API"; anda
```

También puede escribir la clave en `~/.anda/config.yaml` para reutilizarla. La clave `api_key` en `config.yaml` tiene prioridad sobre las variables de entorno.

## Primer lanzamiento

En la primera ejecución, Anda crea el directorio de runtime local y el archivo `~/.anda/config.yaml`. Si la configuración está incompleta, la interfaz de usuario de la terminal mostrará la lista de campos faltantes.

1. Abra `~/.anda/config.yaml`.
2. Complete los campos `family`, `model`, `api_base` y `api_key` o use una variable de entorno para el proveedor del modelo.
3. Guarde el archivo.
4. Actualice los modelos desde Anda Desktop o el panel lateral del navegador, o ejecute `anda models reload`.

Configuración mínima del modelo:

```yaml
model:
  active: "deepseek-v4-pro"
  providers:
    - family: anthropic
      model: "deepseek-v4-pro"
      api_base: "https://api.deepseek.com/anthropic"
      api_key: "TU_CLAVE_API" # Puede dejarse vacío si se establece DEEPSEEK_API_KEY
      labels: ["pro", "brain"]
      disabled: false
```

La etiqueta `brain` hace que el cerebro de memoria prefiera ese proveedor. Si ningún proveedor tiene la etiqueta, las tareas de memoria utilizarán el modelo activo.

## Ejecutar desde el código fuente

Para ejecutar el proyecto directamente desde el repositorio:

```bash
git clone https://github.com/ldclabs/anda-bot.git
cd anda-bot
cargo run -p anda_bot --
```

Utilice un directorio principal (`home`) independiente para aislar identidades, proyectos o datos de prueba:

```bash
anda --home /ruta/a/.anda
```

Comando equivalente para el código fuente:

```bash
cargo run -p anda_bot -- --home /ruta/a/.anda
```

## Actualizar

Si instaló Anda mediante el script de instalación, actualícelo con:

```bash
anda update
```

Gestione el daemon en segundo plano con:

```bash
anda status
anda start
anda stop
anda restart
anda autostart status
```
