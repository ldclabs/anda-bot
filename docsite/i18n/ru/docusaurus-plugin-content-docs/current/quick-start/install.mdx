# Установить Anda

Anda Bot можно установить в виде скомпилированного официального релиза или запустить напрямую из исходного кода репозитория. Готовые релизы рекомендуются для повседневного использования; запуск из исходников лучше всего подходит для участия в разработке, отладки кода и экспериментов с новыми возможностями.

## Установка последнего релиза

### Anda Desktop

Большинству пользователей стоит начать с Anda Desktop: окна чата, рабочей области и значка в трее. Скачайте его со страницы [последнего релиза](https://github.com/ldclabs/anda-bot/releases/latest):

- macOS Apple Silicon: `Anda-mac-arm64.dmg`
- Windows x64: `Anda-win-x64.exe`
- Homebrew: `brew install --cask ldclabs/tap/anda-desktop` (также устанавливает формулу `anda`)

Новые сборки командной строки и приложения для macOS доступны только для Apple Silicon. На Mac с Intel можно собрать из исходного кода.

Anda Desktop использует уже установленный `anda`, а если его нет — устанавливает встроенный `anda` и навыки туда же, куда их ставят скрипты установки (`~/.local/bin` в macOS, `%LOCALAPPDATA%\Programs\AndaBot` в Windows). Так приложение, терминал и расширение Chrome используют один runtime и один демон. В мастере подключения модели можно включить запуск Anda при входе в систему. Значок Anda Desktop в трее заменяет устаревший лаунчер Anda Bot в строке меню, который приложение удаляет.

Если модель не настроена, автоматически открывается **Подключить модель**. Войдите через ChatGPT и подтвердите модель или выберите готовую модель из встроенного `config.yaml` и введите API-ключ. Мастер дождётся загрузки модели. **Настроить позже** сохраняет черновик и напоминание; снова открыть мастер можно через **Настройки → Общие → Подключить модель**. Существующие настройки сохраняются.

### Только командная строка

Через Homebrew:

```bash
brew install ldclabs/tap/anda
```

macOS и Linux через скрипт установки:

```bash
curl -fsSL https://raw.githubusercontent.com/ldclabs/anda-bot/main/scripts/install.sh | sh
```

Если у вас также есть установка через Homebrew, откройте новый терминал и убедитесь, что `command -v anda` указывает на `~/.local/bin/anda` или ваш `ANDA_INSTALL_DIR`; иначе старый бинарный файл Homebrew может перекрыть обновлённый файл из скрипта.

Windows через PowerShell:

```powershell
irm https://raw.githubusercontent.com/ldclabs/anda-bot/main/scripts/install.ps1 | iex
```

Скрипты установки ставят `anda` и навыки, добавляют его в `PATH`, регистрируют автозапуск демона при входе через `anda autostart install` и перезапускают его; повторный запуск скрипта также удаляет устаревший лаунчер. В Windows запись автозапуска выполняет `anda start` и ненадолго показывает окно консоли. В PowerShell вы можете использовать параметры `-NoAutostart` или `-NoStart`; для bash-скрипта задайте `ANDA_NO_AUTOSTART=1` или `ANDA_NO_START=1`.

После завершения установки откройте новое окно терминала и выполните:

```bash
anda
```

## Подготовка API-ключа модели

Вам потребуется хотя бы один API-ключ от провайдера языковых моделей. Пользователи Anda Desktop могут ввести его в разделе **Настройки → Настройка агента**. При запуске через консоль CLI можно временно задать переменную окружения:

```bash
DEEPSEEK_API_KEY=ВАШ_API_KEY anda
```

В консоли Windows PowerShell:

```powershell
$env:DEEPSEEK_API_KEY="ВАШ_API_KEY"; anda
```

Вы также можете сохранить ключ в конфигурационном файле `~/.anda/config.yaml` для постоянного использования. Значение `api_key` из файла `config.yaml` имеет более высокий приоритет по сравнению с переменными окружения.

## Первый запуск

При первом запуске Anda автоматически создает локальную рабочую директорию и шаблон файла `~/.anda/config.yaml`. Если конфигурация окажется неполной, текстовый интерфейс терминала выведет список параметров, требующих заполнения.

1. Откройте файл `~/.anda/config.yaml`.
2. Заполните поля провайдера моделей: семейство (`family`), название модели (`model`), адрес API (`api_base`) и сам ключ (`api_key`) либо оставьте поле ключа пустым при использовании переменных окружения.
3. Сохраните изменения.
4. Обновите конфигурацию из Anda Desktop, боковой панели браузера или выполнив команду `anda models reload`.

Минимальный пример конфигурации:

```yaml
model:
  active: "deepseek-v4-pro"
  providers:
    - family: anthropic
      model: "deepseek-v4-pro"
      api_base: "https://api.deepseek.com/anthropic"
      api_key: "ВАШ_API_KEY" # Можно оставить пустым при установленной переменной DEEPSEEK_API_KEY
      labels: ["pro", "brain"]
      disabled: false
```

Метка `brain` указывает системе долгосрочной памяти использовать данного провайдера по умолчанию. Если ни у одного из провайдеров нет этой метки, задачи памяти будут выполняться на текущей активной модели (active model).

## Запуск из исходного кода

Для прямого запуска из склонированного репозитория:

```bash
git clone https://github.com/ldclabs/anda-bot.git
cd anda-bot
cargo run -p anda_bot --
```

Вы можете изолировать настройки, проекты и тестовые данные разных учетных записей, переопределив домашний каталог:

```bash
anda --home /путь/к/.anda
```

Эквивалентная команда для запуска из исходников:

```bash
cargo run -p anda_bot -- --home /путь/к/.anda
```

## Обновление

Если Anda была установлена с помощью скрипта автоматической установки, обновите ее командой:

```bash
anda update
```

Установки через Homebrew обновляются командой `brew upgrade anda`. **Проверить обновления** в трее Anda Desktop или в настройках проверяет и `anda`, и само приложение. Установка runtime ждёт завершения активных задач; проверка обновления приложения продолжается независимо от того, было ли это обновление установлено, отложено или завершилось ошибкой. Подписанные релизы приложения обновляются без остановки службы; неподписанные сборки нужно обновлять вручную, установив новый пакет приложения.

Для управления фоновой службой (демоном) используйте следующие команды:

```bash
anda status
anda start
anda stop
anda restart
anda autostart status
```
